# Security model

What YTMuse defends, against whom, by what mechanism, and which test fails when the mechanism is removed. Written for W29 (T29.1-T29.5); every row names the suite that holds it. The tests are in `Packages/NativeMusic/Tests/Security` unless another lane is named. Run them with `scripts/test.sh --suite T29`.

## Assets and adversaries

Assets: the Google session (cookies), OAuth codes and tokens, the person's private playlist names, search terms and email address, signed media URLs, the account's local files and keys, and the machine's local network. Adversaries: a hostile or compromised service response; a hostile link, pasted or dropped; another process on the loopback interface or another site opening the sign-in callback; a hostile web page inside the hidden player; a file planted where the widget or a restore reads; the person's own logs and exports, which are read by other people.

Not defended: malware running as the same user (it can read this app's private folder, as it can read any user's files), a compromised operating system, and Google's own page behaviour inside the hidden player (limited, not controlled; see below).

## Trust boundaries and their mechanisms

| Boundary | Mechanism | Held by |
|---|---|---|
| Network egress is an allowlist (SEC02, SEC04) | `NetworkRoute` (exact host, path, method, query names; refuses addresses in every spelling and private names), `SignedMusicPolicy`, `DirectPublicTransport`, the artwork host allowlist, the OAuth token/keys pins; ephemeral sessions with no cookie jar, no cache, no stored credential; redirects refused (or, for artwork, re-checked per hop) | `HostileRouteTests`, `HostileArtworkFetchTests`, `DestinationTests.theTransportPoliciesAcceptNothingOutsideTheInventory` |
| TLS is the system's (SEC04) | No code or property list overrides trust evaluation, answers an authentication challenge, or loosens App Transport Security; session delegates implement redirect refusal only | `BadTLSTests` (fails closed within the retry budget, a mutation is never replayed; source and plist sweep; delegate selectors) |
| Sign-in callback (AUTH02, AUTH03, SEC04) | State and PKCE, one-shot, bound to the attempt's generation and a 3 minute deadline; loopback-only listener with a strict request parser | `HostileCallbackTests` (forged, duplicated, replayed, stale, expired, wrong host/port/path/method, smuggled headers, oversize) |
| Links are navigation only (SEC05) | `LinkPolicy` is pure and exact: no address, port, userinfo, encoding, fragment, hidden character, tracking secret or unknown host; the canonical link handed out is the identifier alone | `HostileLinkTests` (64 hostile links), W26's `LinkPolicyTests` |
| Resources are bounded (SEC05) | Bytes, time, JSON depth and node count, image dimensions and pixels, header sizes; the body is read as a stream and cancelled at the cap whatever the headers claim; artwork is decoded to the display size, never the original | `HostileImageTests`, `HostileBodyTests` (a two-billion-byte stream is pulled for at most 4 KiB), `HostileMetadataTests`, `HostileArtworkFetchTests` |
| Secrets never become text (SEC03, DATA02) | Opaque descriptions **and** hidden Mirror children on every credential-bearing type; `SafeErrorText` is the only way an error becomes stored or shown text; the redactor works on text with the live private context and handles the encodings a redirect produces; the bundle is previewed byte for byte | `CanaryPathTests` (16 paths, 60 delivered canaries, 429 checked outputs), `SafeErrorTextTests` (source sweep), W27's `DiagnosticRedactionTests` |
| Account removal is complete, local and retryable (AUTH06, AUTH09, SEC08) | The lifecycle barrier, per-participant `removeLocal`, a durable "removal pending" tombstone, generation fences in the indexer, publisher and scheduler; no network capability in the removal path | `AccountDeletionTests` |
| Nothing blocks the main actor or an audio callback (ARCH02) | Disk and image work on a serial queue behind a recorded seam; actors for stores and scheduling; no app-owned audio callback in the product | `ThreadAffinityTests` |
| Least privilege (SEC06) | The app asks for the App Group entitlement and nothing else; the widget is sandboxed with the App Group; hardened runtime on every target; no usage description for a feature the person has not activated | `DestinationTests.entitlementsAndUsageDescriptionsAreTheLeastTheAppNeeds`, `scripts/check-destinations.py --binary` |
| No remote code or configuration (ARCH05, ARCH07, SEC09) | No external package, no process launch, no plug-in loading, no downloaded script (every `WKUserScript` is a compiled constant); the updater (W30) is opt-in and verified | `DestinationTests.theProjectDeclaresNoExternalDependencyAndNoRemoteExecutableUpdate` |
| Real stores are never touched by tests (SEC10) | W27's guarded wrappers and sweeps; W29's fakes are in-memory or scratch directories, the vault is a fake, URL protocols answer every request | the production-store guard in every suite's preamble |

## Hardening round 2 (TH2)

Closed after W29's review, each held by a test that failed on the old code:
- **Redaction.** `DiagnosticRedactor` now also removes URLs written with doubled or unicode-escaped slashes in JSON (`\\/`, `\u002f`, and `\u003d` / `\u0026` / `\u0040` inside them), URLs with no scheme (`host.tld/path?...`, a protocol-relative `//host/...`, an IPv4 address with a path) under a fixed list of top-level domains, `&#x40;` / `&#X0040;` / `&#0064;` e-mail entities, and the bare `OSID` and `AEC` cookies. A named first-party host keeps its name in the schemeless form, as in the scheme form. (`RedactionGapTests`.)
- **Error text.** `SafeErrorText.describe` keeps an app error's case or type name and labels but replaces every non-numeric payload with `…`: a playlist name or a typed search has no shape a pattern could find. (`ErrorPayloadTests`, and the `error.text` canary path.)
- **Status messages.** `StatusNotification.make` has no `reason` parameter any more, so error text cannot reach a system notification; the sweep has a `status.notification` path.
- **Destinations.** The updater's redirect and feed-address policies are probed with the host corpus, and may accept `github.com` (feed) and `github.com` plus `*.githubusercontent.com` (redirect) only.
- **Main thread.** The account photo is decoded off the main actor (`AvatarDecoding`), and `MainActorSweep` now treats SwiftUI views, view modifiers and representables as main-actor code. The widget view's decode (a bounded 32 KB thumbnail inside the widget extension) is the one reviewed exception.
- **Real-store guard.** `GuardedDefaults` derives whether its domain is real from the domain (a file inside the temporary folder is the only throwaway); `RealStores.resolved` is in the source sweep and is named only by the updater's file guard and the destructive-action verification.

## What W29 found and fixed

1. **A `dump`, debugger print or Mirror-based logger of a network request, response or envelope printed the URL (with a search term in its query), the body and the credential reference**, because the safe `description` is not consulted by Mirror. Fixed by hiding the children (`CustomReflectable`) on `BoundedRequest`, `BoundedResponse` and `NetworkEnvelope`.
2. **The log redactor missed encoded redirects**: a URL travelling as a parameter of another URL (`continue=https%3A%2F%2F...`), text encoded two or three times (`%2520`, `%2540`), and URLs inside JSON strings (`https:\/\/`) kept the host, the signature and the private names. Fixed in `DiagnosticRedactor`; also bare cookie names (`SIDCC`, `SOCS`, `CONSENT`, `PREF`, `VISITOR_PRIVACY_METADATA`, `YSC`, `NID`, `1P_JAR`).
3. **Error text** was formed by `String(describing: error)` in the queue and playback state fields; a Foundation error prints its failing URL and user info. Fixed with `SafeErrorText`, a sweep that forbids the old forms, and a stricter path scrub (a home-folder path can hold spaces).
4. **The hidden player's artwork loader** downloaded the whole body before checking its size, trusted a declared length of any size, and followed redirects to any host (it checked the final host only after the request had been made). Fixed: redirects are re-checked per hop against the allowlist, a declared length above the cap is refused before a byte is read, and the body is streamed and cancelled at the cap.
5. **`NetworkRoute` could be built for an address** (`127.0.0.1`, `10.0.0.1`, `169.254.169.254`, `0x7f.0.0.1`) or a private name (`.local`, `.internal`, `.lan`, `.home.arpa`). The allowlist meant none existed, but the constructor now refuses them, so an arbitrary link cannot become a local-network request even by a future mistake.
6. **The widget publisher decoded artwork and wrote, read and deleted the snapshot file on the main actor.** Both now run on one serial queue behind a recorded seam (`WidgetSnapshotIO`); the queue keeps the order, and every continuation checks that no barrier decided meanwhile. The one remaining wait is the explicit privacy reset's single unlink: the main actor calls `DispatchQueue.sync` on that queue, which may run the closure on the calling (main) thread. It is a reviewed, explicit exception, pinned by `ThreadAffinityTests.onlyTheExplicitPrivacyResetWaitsForTheFileQueue` (exactly one operation, the unlink). It is not in `MainActorSweep`'s allowlist and the sweep cannot see a `.sync` call on a non-main queue; the test is what holds it.

## Known limits (stated, not hidden)

- **The hidden player is a web page.** YouTube's page decides its own subresource hosts, and advertising is shown, not blocked (Playback-Addendum). The application limits navigation and the script bridge but cannot enumerate the page's hosts.
- **The app is not sandboxed** (hardened runtime, direct distribution). It needs no entitlement that prevents a sandboxed build on its own, but the loopback listener and the WebKit use mean a sandboxed build needs `network.client` and `network.server`; that is future work, not a claim.
- **Local data is not encrypted at rest** except downloaded media and the Keychain. See [Privacy.md](Privacy.md).
- **Live evidence is separate**: a packet capture of a real session, a bad-certificate server on a controlled network, a signed Release bundle audit, and an installed widget and Spotlight observation are not part of T29.
