# Owned native playback evidence

`measure.sh` runs the same complete local cases as T16: original component checks,
selected production transport/DSP, real queue handoff/overlap/cancellation, native
AAC/M4A and Opus/CAF trim/reference checks, and W14 retained provider composition.
All new Play calls use native offline/manual rendering enabled before graph start.
Existing T06 hardware-capable tests retain their established <=0.001 cap.

Original sine, impulse, alternating-boundary and constant samples are generated by
the checked-in Swift tests; these original media signals are dedicated CC0-1.0.
W06 bundled WAVE provenance is Playback/Resources/Provenance.txt. The test encoder
uses only native AVAudioFile APIs. Reference PCM decode uses AVAudioFile independently
of the selected transport's AVAssetReader. Packet metadata is read with AudioFile
APIs, not guessed from an extension. No personal/source media or credentials are used.

Fixed oracle: exact logical frame counts, <=1 source frame timestamp uncertainty,
and 2e-6 absolute PCM/native-reference sample error. EQ center-response tolerances
remain predeclared separately; lossy amplitude differences do not permit missing,
repeated or zero-padded logical samples. Setting W16_CORPUS_OUTPUT to a new evidence
folder preserves original/encoded corpus bytes with per-file hashes in the raw log.
Temporary inputs are otherwise uniquely named and removed. They are owned fixtures,
not plaintext exports from the encrypted store.

Nine empty SPM products and child-entry no-ops are never counted as substantive
passes. T14 subprocess observations remain separate from its parent method count.
Raw native build logs retain original whitespace. Local correctness does not close
physical routes, source media/auth/ads/rights, resource budgets, soak or release gates.
