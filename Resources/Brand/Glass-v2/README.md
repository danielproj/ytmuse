# YTMuse glass icon sources

Generated in response to the user's explicit glass-design request using the built-in image_gen edit tool. The original YTMuse identity and v1 evidence are retained in the parent directory.

- `YTMuse-Glass-AppIcon-master-v2.png`: refined glass app-icon composite, 1254px square with alpha.
- `YTMuse-Glass-Foreground-v2.png`: separate translucent musical M foreground, 1254px square with alpha, for the layered icon workflow.
- `YTMuseGlass.iconset/` and `YTMuseGlass.icns`: ten mechanically resampled macOS representations and a flattened native compatibility icon. They do not establish adaptive Icon Composer integration.
- `generation-prompts.json`: exact prompts and generation method.
- `asset-manifest.json`: generated file hashes.

V01 integrates and validates the actual native glass icon and interface. These new sources have not replaced the accepted W04 bundle resources yet. The monochrome menu-bar template remains in the parent directory for native system rendering.

## V01 layered integration

`YTMuse.icon` is the actual Xcode-compiled layered source. Its format is grounded in the installed Xcode macOS Icon Composer template and Apple's Landmarks sample icon document. The original generated foreground PNG is preserved byte-for-byte in `Assets/Musical-M.png`. `Musical-M.svg` places those same PNG bytes inside an inset SVG canvas so the native enclosure does not clip the musical mark; it does not regenerate or retouch the raster. The native background is a burgundy/charcoal gradient and the foreground is a separate glass layer. The original composite, compatibility icon, ten-size iconset and exact generation prompts remain unchanged.

`build-layered-icon.sh [output-directory]` uses the selected Xcode's bundled `ictool` to export Default, Dark and Mono at 16–1024 pixels. The observed tool accepts Mono even though its invalid-rendition error lists only Default/Dark/Tinted/Clear names. These exports verify the source renderer, independently of the app's compiled Assets.car. Xcode compiles actual Aqua, Dark Aqua and tintable icon stacks. `YTMuseGlass.icns` is bundled separately as the explicitly flattened compatibility output. The default `YTMuse.icns` is now generated by actool from the layered document; v1 `../YTMuse.icns` remains preserved in source.

The app no longer overrides its application icon with a flattened NSImage on startup. Native bundle icon selection owns runtime appearance. See V01 evidence for compiled icon extraction/resource resolution and the distinction between renderer checks and actual desktop appearance observations.

The icon document uses the group/layer configuration structure from Apple’s Landmarks sample, with YTMuse artwork and background values. The sample license is retained in `Apple-Sample-Code-LICENSE.txt`; no Apple sample artwork is included.
